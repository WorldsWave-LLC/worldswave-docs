# Contributing

Corrections and clarifications are welcome.

## Reporting an error

Open an issue with the document name and what is wrong. Documentation errors
that describe the product incorrectly are treated as bugs.

## Submitting a change

1. Fork the repository and edit the file in `docs/`.
2. Keep the existing style — see below.
3. Open a pull request describing what changed and why.

## Style

These documents are written to be quoted, by people and by AI assistants.

- **Headings are questions.** "How do I boost a post?" not "Boosting".
- **A direct answer of roughly 40–60 words sits immediately under every heading**, before any detail.
- **Sections stay self-contained** — a reader arriving at one heading should not need the one above it.
- **Concrete numbers, not vague claims.** "$0.225 per click" beats "affordable".
- **Short paragraphs**, bullets for lists, tables for comparisons.
- **Do not state a number you cannot source from the product.** If the product is ambiguous or wrong, say nothing and open an issue instead.

## Canonical version

The [WorldsWave Help Center](https://worldswave.help.center) is the canonical
published version. Merged changes here are mirrored there by the WorldsWave team.
